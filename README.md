# Chrono-Walk Photo Challenge

An observational photo walk sequence puzzle game designed for GitHub Pages.

## 🎮 Gameplay Mechanics
Players must analyze visual clues across photo walk snapshots—such as shadow lengths, sun angles, and ambient lighting—to reconstruct the correct chronological sequence.

## 🚀 Play Live
Host this repository on GitHub Pages to play live!
